# 妄想路線バス 1.0.0 同梱の地理・路線データ

この配布物は、妄想路線バス 1.0.0 のアプリに同梱する、機械可読な完成データを無料で提供するものです。App Storeの初版公開メニューは4系統8方向ですが、アプリには検証用を含む35個の路線JSONと、共通構造物JSON1個が含まれています。この配布物にも同じ36ファイルを含めます。一般利用者が作成・保存した路線や設定は含みません。

## ファイルと改変

routes/*.json と structures/tokyo-structures.json は、1.0.0に同梱する同名のJSONとバイト単位で同じです。道路のつながり・車線数・停留所位置・標高・構造物には推定と簡略化があり、実際の交通案内・ナビゲーションには使えません。取得時期等は各JSONのsourceを参照してください。

source-manifest.json に全36ファイルのサイズとSHA-256を記録しています。国土地理院の航空写真・標高・背景地図画像、PLATEAUの3D Tiles、アプリのプログラム、生成ロゴ・アイコン、個人の保存情報は、このデータ配布物には含めていません。

この提供はデータの再利用用です。アプリのプログラム、名称・標章、交通事業者との提携や承認について権利を与えるものではありません。交通事業者の標章・塗装は使っていません。
